# Viper Asset Drop Intake

Front-door asset drop folder:

`C:\Users\U\Documents\Viper_Asset_Drop`

This folder is the easy staging area for anything downloaded for Viper Studios before it is sorted into the project.

## Purpose

Guy can drop source assets here without digging through Viper project folders.

Expected drop types:

- Leather jacket meshes and textures.
- Jeans, sneakers, necklace, hair, eyes, skin, and makeup sources.
- Reference images.
- ZIP packages.
- FBX, OBJ, GLB, BLEND, PNG, JPG, and texture sheets.
- IMVU free/derivable assets with source notes.
- Blender, CC0, permissive, commissioned, or Viper-authored base assets.

## Intake Rule

This folder is staging only.

Files in `C:\Users\U\Documents\Viper_Asset_Drop` are not considered organized Viper library assets until they are inspected, categorized, source-tagged, and copied into the proper Viper asset structure.

Every imported asset should receive:

- Product category.
- Source lane.
- Original filename.
- Source URL or product ID when available.
- Permission/license note.
- Target avatar, object, room, vehicle, or scene.
- Target slot, material, body part, attachment node, or surface.
- Editable source location.
- Runtime preview/export location.

## Sorting Destination

After inspection, assets should move into the proper Viper structure, such as:

- Avatar bases.
- Aria character assets.
- Clothing and wearable products.
- Accessories.
- Hair.
- Texture blocks.
- Reference boards.
- Room and furniture assets.
- Vehicle and ship assets.
- Export-ready runtime assets.

The drop folder stays simple. Viper handles the sorting.
