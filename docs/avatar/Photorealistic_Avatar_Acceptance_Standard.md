# Photorealistic Avatar Acceptance Standard

## Evaluation Philosophy
Do not declare an avatar photorealistic because one still image looks good. Realism must hold up across 360 degrees of inspection, mechanical deformation, and runtime execution.

## Independence Categories
Photorealism must be evaluated independently across the following attributes:
- Identity
- Facial geometry
- Profile silhouette
- Skin, Eyes, Teeth, Hair, Neck, Shoulders, Hands
- Body proportions
- Clothing fit, Cloth behavior
- Facial animation, Lip synchronization
- Motion, Lighting response

## Required Evidence
Before any generation is considered "Verified Photorealistic," it must physically produce and pass the following tests:

1. **Static Validation**:
   - Neutral front render
   - Profiles (Left and Right)
   - Three-quarter views
   - Full-body views
   - Close-up skin test
   - Hairline test

2. **Deformation Validation**:
   - Expression tests
   - Speech test
   - Eye-motion test
   - Extreme-pose deformation test

3. **Runtime Validation**:
   - Walking test
   - Clothing-change test
   - Reality Gate runtime test (Instantiated in Headquarters)
