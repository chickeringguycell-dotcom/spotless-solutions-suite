## Conclusion
Because the canonical source package lacks a true `LEFT_PROFILE` or `RIGHT_PROFILE` image, almost all profile geometric measurements must be derived from the 3D Z-coordinates generated by MediaPipe from a 2D Frontal image. This is mathematically defined as **INFERRED** or **ESTIMATED**. 

Consequently, SentinelQC Profile rules will automatically downgrade their classification from `VERIFIED` to `PROVISIONAL` to honestly reflect the statistical uncertainty of the source data. Certain metrics (Ear Width, Skull Silhouette) are classified as `INSUFFICIENT` and will be `NOT_MEASURED`.
