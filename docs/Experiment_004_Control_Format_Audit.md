# Experiment 004 Control Format Audit

## Objective
Verify the compatibility of the `Station 7C` control image output with the `control_v11p_sd15_openpose.pth` ControlNet model.

## Finding
**CLASSIFICATION: FORMAT_MISMATCH**

## Detailed Audit

### 1. The OpenPose ControlNet Standard
The standard `control_v11p_sd15_openpose.pth` model is trained exclusively on images generated by the OpenPose preprocessor. A valid OpenPose control image consists of:
- **Body Keypoints**: 18 specific skeletal joints connected by thick lines colored using a precise RGB heatmap spectrum (e.g., neck-to-right-shoulder is a specific shade of green/yellow).
- **Facial Keypoints (OpenPose Face)**: 68-70 keypoints represented by specific colored dots and connecting lines mapping the eyes, nose, and mouth contours.
- **Background**: Solid black (`#000000`).

### 2. Station 7C Current Output
A review of the rendering logic in `scripts/station_7c_camera_geometry.py` (Lines 79-88) reveals:
```python
img = np.zeros((height, width, 3), dtype=np.uint8)
for lm_id, pt in transformed_landmarks.items():
    if pt["status"] in ["MEASURED", "PROJECTED", "ESTIMATED"]:
        px = int(pt["x"] * width)
        py = int(pt["y"] * height)
        cv2.circle(img, (px, py), 2, (255, 255, 255), -1)
```
- **Geometry**: It plots a scatterplot of disconnected points.
- **Color**: Every point is pure white `(255, 255, 255)`.
- **Connections**: There are no colored skeletal lines.
- **Topology**: It uses the internal Station 7C canonical topology, not the OpenPose 18/68 standard.

### 3. Impact on Experiment 003
Because the input control image was just a scatterplot of white dots, the OpenPose ControlNet could not recognize any human anatomical structure. 
- In **Experiment 002 (ControlNet Only)**, the ControlNet likely treated the white dots as generic edge-noise or failed entirely, allowing the Text Prompt to freely generate a profile face (coincidentally aligning with the text prompt "profile" or just overriding the garbage control). 
- In **Experiment 003 (Dual Conditioning)**, the garbage OpenPose control + the heavy IP-Adapter identity signal completely corrupted the diffusion process, resulting in an unmeasurable blob.

## Conclusion
The Station 7C output is **not** an OpenPose control image. It is a custom white-dot scatterplot. Feeding this into `control_v11p_sd15_openpose.pth` guarantees a `FORMAT_MISMATCH`. The geometry was never mathematically enforced by OpenPose in any prior experiment.
