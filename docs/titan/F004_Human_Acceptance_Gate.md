# F004 Human Acceptance Gate

## Evaluation Criteria (Phase 13)

### Face-Visible Views
For each face-visible view, Guy must judge:
- Same person
- Eye shape
- Eye spacing
- Nose shape and projection
- Lips
- Mouth placement
- Jaw
- Chin
- Forehead
- Hairline
- Ear shape and placement
- Skin tone
- Apparent age
- Head proportions
- Neck proportions
- Photorealism
- Major artifacts

### Rear Views
For rear views, Guy must judge:
- No visible face
- Plausible rear skull
- Plausible ears
- Plausible neck
- Plausible back of hair
- Consistency with the source person
- No duplicate anatomy
- No melted or distorted structures
- Photorealism

### Human Verdicts
Use ONLY these human verdicts:
- ACCEPT
- ACCEPT_WITH_MINOR_DEFECTS
- REJECT_IDENTITY
- REJECT_ANATOMY
- REJECT_VIEW
- REJECT_ARTIFACTS
- INSUFFICIENT_EVIDENCE
