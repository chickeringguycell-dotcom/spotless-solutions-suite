# Titan Next Component Benchmark

**Phases 6-8: Candidate Installation and Ablation Testing**

### Candidate 1: PanoHead (Tier A)
* **Goal:** Synthesize full-head geometry (hair, ears, rear skull) via GAN Inversion.
* **Result:** `FAILED_AT_INSTALLATION_GATE`
* **Root Cause:** PanoHead's `projector.py` threw a `KeyError: 'GB001_SOURCE_FRONT.jpg'`. PanoHead cannot natively ingest a raw photograph; it strictly requires a pre-processed `dataset.json` containing ground-truth 3D camera extrinsics generated by an external, non-commercial deep learning stack (`3DDFA_V2`). 
* **Ablation Data:** N/A (Failed to execute).
* **Action:** Aborted per the autonomous pipeline constraints (avoiding the construction of an entire secondary non-commercial pipeline just to align one image).

### Candidate 2: DECA (Tier B)
* **Goal:** Synthesize the base skull and ears via the FLAME topology.
* **Result:** `FAILED_AT_INSTALLATION_GATE`
* **Root Cause:** DECA requires `deca_model.tar` and the FLAME generic model. The Max Planck Institute (MPI) explicitly prohibits automated redistribution of these files. Downloading them requires registering an academic email, accepting a non-commercial agreement, and passing a manual firewall.
* **Ablation Data:** N/A (Failed to download weights).
* **Action:** Aborted per the Academic Firewall Rule. 

### Conclusion
No candidate successfully passed the Phase 6 autonomous installation and testing gate. 
Project Titan remains bottlenecked at the **Full-Head Geometry** gap. 
* The **PanoHead architecture** remains the correct mathematical solution, but requires Viper Studios to build its own commercial camera-alignment preprocessor to replace 3DDFA_V2.
* The PRNet baseline remains the only successful geometry extraction tool tested to date.
