# Nano Banana / Gemini Availability Audit

## Official Audit Results
1. **Model Reference:** "Nano Banana" is not an official, publicly documented model name in the Google AI developer documentation. It likely refers to an internal codename or a conversational artifact from prior chats.
2. **API Availability:** There is no model identifier named "nano-banana" or similar available through the standard Gemini API (`models/gemini-1.5-pro`, `models/gemini-1.5-flash`, etc.). 
3. **Public Weights/Source:** The weights and source code for the proprietary Gemini models are not publicly available or open-source.
4. **License:** Proprietary.
5. **Exact Model for Benchmark:** The exact sub-model used to generate the benchmark cannot be programmatically recovered from the images because EXIF/metadata describing internal backend routing is not embedded in the returned bytes.
